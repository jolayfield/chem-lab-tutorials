The user provides a path to a plain-text slide outline generated by `/basic-slides` (e.g. `lecture-slides/molecular-dynamics.md`). Read that file, then produce a fully-formatted Marp Markdown file with equations, design, and visual structure.

## Step 1 — Read the input file

Use the Read tool to load the file at the path the user provided. If the file does not exist, report the error and stop.

## Step 2 — Produce Marp Markdown

Write a new file at `lecture-slides/<basename>-finished.md` (e.g. `molecular-dynamics-finished.md`).

### Slide separator rules

- Each slide begins with `---` on its own line (Marp slide separator).
- The first slide (title) does NOT need a leading `---`.
- Section-header slides use `<!-- _class: section-slide -->` immediately after their `---`.

### Slide format patterns

**Title slide:**
```markdown
# [Lecture Title]

[Course name] · [Date placeholder]
```

**Learning objectives slide:**
```markdown
# Learning Objectives

- Objective one
- Objective two
```

**Section-header slide:**
```markdown
---
<!-- _class: section-slide -->

# Section Title

- Topic A
- Topic B
- Topic C
```

**Content slide:**
```markdown
---

# Slide Title

- Bullet point
- Bullet point

<div class="equation-box">

$$[relevant equation]$$

</div>
```

**Content slide with figure placeholder:**
```markdown
---

# Slide Title

- Bullet point

<div class="figure-placeholder">
[FIGURE: brief description of what diagram or plot would go here]
</div>
```

## Step 3 — Add equations

For each content slide, identify where a key equation would strengthen the explanation and add it as a `<div class="equation-box">` block. Use KaTeX syntax (`$...$` inline, `$$...$$` display).

Guidelines:
- Add at most one equation box per slide — do not crowd slides
- Only add equations that are directly relevant to the slide's content; do not add equations for the sake of it
- Section-header slides and the title slide never get equations
- Prefer display equations (`$$...$$`) over inline for the equation box

Examples of appropriate additions by topic:
- Newton's equations of motion → $F = ma$ displayed as $\mathbf{F}_i = m_i \ddot{\mathbf{r}}_i$
- Velocity Verlet integrator → the position and velocity update equations
- Lennard-Jones potential → the 12-6 LJ form
- Boltzmann distribution → $P_i \propto e^{-E_i / k_B T}$
- RMSD → the RMSD formula
- Radial distribution function → the g(r) definition

If a slide has no natural equation, do not force one.

## Step 4 — Add figure placeholders

Add a `<div class="figure-placeholder">` on slides where a diagram, plot, or schematic would be expected in a real lecture. Examples:
- A workflow slide → flowchart placeholder
- Periodic boundary conditions → schematic placeholder
- Force field terms → diagram of bond/angle/torsion
- Energy minimization → energy landscape plot
- MD trajectory output → example trajectory/RMSD plot

Limit to slides where a figure is genuinely informative, not every slide.

Use the Write tool to save the finished Marp Markdown to `lecture-slides/<basename>-finished.md`.
